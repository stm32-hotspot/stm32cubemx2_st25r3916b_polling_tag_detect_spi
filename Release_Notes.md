# Release Notes for <mark>stm32cubemx2_st25r3916b_polling_tag_detect_spi</mark>

# Purpose

This example demonstrates how to use the ST25R3916B part driver with STM32CubeMX2 for polling tag detect over SPI.

No limitation raised for this example.

Configuration and code generation features require STM32CubeMX2 >= 1.1.0.
